# دورهمی — اپ اندروید (مرحلهٔ ۰: اسکلت)
- Kotlin + Jetpack Compose. نام بسته: ir.dorehami.app (پس از انتشار قابل تغییر نیست).
- با هر بارگذاری در GitHub، بخش Actions یک APK آزمایشی (debug) می‌سازد؛ از همان صفحه دانلود کنید.
- کلید امضا (*.jks) و هر رمزی را هرگز داخل این مخزن نگذارید.
- وضعیت: ساخته نشده و امتحان نشده؛ اولین اجرای GitHub Actions اولین آزمون واقعی است.
