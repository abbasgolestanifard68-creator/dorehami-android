# تیم iOS دورهمی — نقش‌ها و تسک‌ها

توضیح: این نقش‌ها برای افراد واقعی تیم نوشته شده‌اند. پایهٔ کد (`ios/`) را Claude نوشته و هنوز کامپایل نشده است؛ تا ورود افراد واقعی، همهٔ نقش‌ها در عمل توسط Claude پوشش داده می‌شوند.

| نقش | مسئولیت | تسک‌های اول |
|------|-----------|-------------|
| **معمار/رئیس iOS** | معماری، بازبینی PR، هماهنگی با اندروید و بک‌اند | اولین ساخت موفق روی macOS؛ تأیید مینیمم iOS 16 |
| **توسعه‌دهنده UI (SwiftUI)** | صفحات و انیمیشن، RTL و حالت شب | تطابق با طرح طراح، بررسی تقویم شمسی روی اندازه‌های مختلف |
| **شبکه و احراز هویت** | `Api.swift`، تمدید توکن با قفل هم‌زمانی | اضافه کردن قفل (actor) برای refresh؛ هماهنگی قرارداد با بک‌اند |
| **چت و داده** | `ApiChatRepository`، WebSocket، ذخیره آفلاین (SwiftData/Core Data) | اتصال به API واقعی؛ صف ارسال آفلاین |
| **امنیت** | Keychain، ATS، رمزنگاری پیام‌ها | بازبینی ذخیرهٔ توکن؛ مدل رمزنگاری چت |
| **اعلان‌ها (APNs)** | ثبت دستگاه، هماهنگی با بک‌اند | گواهی/کلید APNs، `POST /devices` |
| **QA iOS** | تست روی آیفون‌های مختلف، همان قالب باگنویسی اندروید | تست ثبت‌نام با ارقام فارسی، قطع اینترنت، Dynamic Type |
| **DevOps/انتشار** | CI روی macOS، امضا، TestFlight | حساب Apple Developer، Secrets برای گواهی، fastlane |

## قوانین کار
- هر کار در شاخهٔ جدا، بازبینی توسط یک نفر از نقش دیگر؛ تغییر منطق اعتبارسنجی/تقویم همزمان در اندروید و iOS اعمال شود.
- همان قرارداد API برای هر دو پلتفرم؛ گزینه مستقل در یک طرف نگیرید.
- هیچ کلید/گواهی/رمزی در مخزن قرار نگیرد.
