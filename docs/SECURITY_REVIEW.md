# بازبینی امنیت و حریم خصوصی — کد اندروید فعلی

ایجنت: security-privacy — دامنه: شاخهٔ `claude/jalali-datepicker` (PR #1). روش: خواندن کد، بدون اجرای اپ و بدون تست نفوذ. موارد زیر فقط از خواندن کد به دست آمده‌اند.

## موارد سالم

- `AndroidManifest.xml`: فقط مجوز INTERNET؛ `allowBackup=false`؛ تنها یک Activity (لانچر) exported است؛ لینک عمیق ندارد.
- ارتباط با سرور فقط HTTPS (در targetSdk ۳۵ ترافیک بدون رمز پیش‌فرض مسدود است).
- توکن‌ها با AES-GCM و کلید Android Keystore ذخیره می‌شوند؛ توکن در لاگ نیست.
- دکمهٔ «ورود آزمایشی» با `FLAG_DEBUGGABLE` محدود شده و در نسخهٔ release نمایش داده نمی‌شود؛ توکنی ذخیره نمی‌کند.
- موقعیت مکانی هنوز در کد نیست (مجوز مکان تعریف نشده).

## از نظر حریم خصوصی (برای آینده)

در اپ هنوز دادهٔ حساسی جز شماره موبایل، نام، تاریخ تولد و آیدی اینستاگرام نیست و همه به سروری می‌روند که هنوز وجود ندارد. قبل از نقشه: سیاست حریم خصوصی، رضایت صریح موقعیت، حالت نامرئی، حذف داده و حداقل سن باید آماده شوند (بک‌لاگ ردیف ۴).

## چیزی که بررسی نشد

اجرای واقعی اپ، تست نفوذ، تاریخچهٔ همهٔ کامیت‌ها برای رازها (فقط نام فایل‌ها و پیام‌ها دیده شده، نه محتوای دقیق همهٔ کامیت‌ها).
