# تسک‌ها به تفکیک نقش (برای تبدیل به GitHub Issue)

**نفر ۱ (محصول):** تعریف محدودهٔ نسخهٔ اول (چت ساده یا همراه با نقشه)؛ تعیین حداقل سن و قوانین ثبت‌نام.
**نفر ۲ (Scrum):** ساخت Issueها از این فهرست، جلسهٔ روزانه، برچسب‌گذاری.
**نفر ۳ (طراح):** طرح صفحات لیست گفتگو، چت، پروفایل؛ چون اپ RTL است طرح‌ها RTL باشند.
**نفر ۴ (QA):** تست دستی ورود/ثبت‌نام با ارقام فارسی، قطع اینترنت و چرخش صفحه؛ ثبت باگ با قالب تعیین‌شده.
**نفر ۵ (Android ۱):** صفحهٔ لیست گفتگو و چت روی داده نمونه، سپس اتصال به API.
**نفر ۶ (Android ۲):** Room و صف ارسال، سپس رسانه.
**نفر ۷ (iOS):** پروژهٔ iOS با همان قرارداد API.
**نفر ۸ (فرانت/مشترک):** رشته‌ها به strings.xml، کامپوننت‌های مشترک، پنل مدیریت در صورت نیاز.
**نفر ۹ (بک‌اند ۱):** تأیید login/register، پیاده‌سازی refresh/logout و ثبت دستگاه.
**نفر ۱۰ (بک‌اند ۲):** WebSocket، گفتگوها و پیام‌ها، ارسال FCM.
**نفر ۱۱ (DevOps):** خرید سرور و دامنه، HTTPS، `gradlew`، امضای release در Secrets (نه داخل ریپازیتوری).
**نفر ۱۲ (امنیت):** بازبینی ذخیرهٔ توکن، محدودیت نرخ ورود، مدل رمزنگاری پیام، بازبینی قبل از انتشار.
