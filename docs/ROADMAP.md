## مرحلهٔ ۱ — پایه (در جریان)
- [x] ورود و ثبت‌نام، نرمال‌سازی ارقام فارسی و شماره موبایل
- [x] ذخیرهٔ توکن با Keystore، تمدید خودکار توکن (فرض‌شده، نیازمند تأیید بک‌اند)
- [x] تست واحد اعتبارسنجی و اجرای آن در CI
- [ ] اولین ساخت موفق APK در GitHub Actions
- [ ] خرید سرور/دامنه و اتصال Config.API_BASE
- [ ] `gradlew` در ریپازیتوری (روی کامپیوتر: `gradle wrapper --gradle-version 8.10.2`)

## مرحلهٔ ۲ — هستهٔ چت
- [x] رابط لیست گفتگو و صفحهٔ چت روی داده نمونه (FakeChatRepository)؛ اتصال به API واقعی باقی است
- [x] رفع هم‌پوشانی با نوار وضعیت/کیبورد در اندروید ۱۵ (لبه‌به‌لبه)
- قرارداد API و WebSocket (docs/API_CONTRACT.md) نهایی شود
- لیست گفتگوها، صفحهٔ چت، ارسال/دریافت لحظه‌ای، وضعیت تحویل و خوانده‌شدن
- ذخیرهٔ آفلاین (Room) و صف ارسال
- اعلان‌ها با FCM

## مرحلهٔ ۳ — امکانات کامل
- چت گروهی، رسانه (عکس، فایل، صدا)، جست‌وجوی مخاطب
- نقشه/دورهمی‌یابی (فقط اگر در محدودهٔ محصول باشد؛ نیازمند تصمیم مالک)

## مرحلهٔ ۴ — انتشار
- امضای release، R8/ProGuard، بررسی امنیتی، تست دستگاه‌های مختلف
