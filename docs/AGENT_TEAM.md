## نحوه کار

- یک نشست اصلی Claude «رئیس تیم» است: خواستهٔ شما را به تسک تقسیم می‌کند، به ایجنت‌های مناسب می‌سپارد، نتیجه را جمع می‌کند و به فارسی گزارش می‌دهد.
- ایجنت‌ها خودشان نمی‌توانند ایجنت دیگری را صدا بزنند؛ همه از طریق رئیس تیم هماهنگ می‌شوند.
- بازبین (QA و امنیت) همیشه با ایجنتی غیر از نویسنده انجام می‌شود.
- هر کار: شاخه `claude/<موضوع>` ← PR ← بازبینی ← Merge توسط مالک.

## چه جایی اجرا می‌شود

- **Claude Code** (ترمینال یا برنامه دسکتاپ): ایجنت‌های پروژه را از `.claude/agents/` می‌خواند. نیازمندی‌های سیستم: Windows 10 نسخه 1809 به بالا، macOS 13+ یا لینوکس. روی Windows 7 نصب نمی‌شود.
- برای کار از مرورگر یا گوشی: از اپ Claude و نسخه‌های ابری Claude Code استفاده کنید (دسترسی و شرایط را از code.claude.com بررسی کنید).

## محدودیت‌های صادقانه

- ایجنت‌ها آدم نیستند و نمی‌توانند دامنه بخرند، مجوز نشان بگیرند یا روی گوشی تست کنند. این کارها با مالک است.
- هیچ ایجنتی نمی‌تواند مطمئن باشد که کد کامپایل می‌شود مگر نتیجه CI را ببیند.
- بک‌اند و سرور هنوز وجود ندارند؛ ایجنت‌های بک‌اند طرح و کد می‌نویسند، ولی راه‌اندازی و هزینه با تأیید مالک است.
