# دورهمی | Dorehami Android

کلاینت اندرویدی بومی دورهمی با Kotlin و Jetpack Compose.

> وضعیت فعلی: نسخه توسعه‌ای و متصل به داده‌های نمونه در بخش چت. این مخزن هنوز محصول آماده انتشار یا دارای بک‌اند عملیاتی تأییدشده نیست.

## فناوری‌ها

- Android / Kotlin
- Jetpack Compose و Material 3
- حداقل Android API 26 و هدف compile/target SDK 35
- JDK 17
- Gradle 8.10.2 در CI
- ذخیره‌سازی توکن با Android Keystore و AES-GCM

## ساخت و آزمون

در GitHub Actions، گردش‌کار `.github/workflows/android.yml` آزمون‌های واحد و ساخت APK آزمایشی را اجرا می‌کند.

برای ساخت محلی، Android SDK و Gradle 8.10.2 را نصب کنید:

```bash
gradle :app:testDebugUnitTest --no-daemon
gradle :app:assembleDebug --no-daemon
```

خروجی نسخه debug در مسیر زیر قرار می‌گیرد:

```
app/build/outputs/apk/debug/
```

فایل APK خروجی CI نیز به‌صورت Artifact با نام `dorehami-debug-apk` در اجرای موفق GitHub Actions قابل دریافت است.

## وضعیت قابلیت‌ها

| قابلیت | وضعیت |
|---|---|
| رابط ورود و ثبت‌نام | پیاده‌سازی اولیه؛ نیازمند تطبیق با جریان OTP محصول |
| نشست و نگهداری توکن | پیاده‌سازی محلی با Keystore؛ نیازمند آزمون روی دستگاه |
| فهرست گفتگو و صفحه چت | رابط کاربری با FakeChatRepository |
| API واقعی و احراز هویت OTP | هنوز بک‌اند عملیاتی تأیید نشده |
| پیام‌رسانی لحظه‌ای و ذخیره آفلاین | در انتظار قرارداد و بک‌اند |
| نقشه، تماس، استوری، گروه و اشتراک | در نقشه راه؛ هنوز پیاده‌سازی نشده |

## تنظیم سرور

آدرس فعلی API در `app/src/main/kotlin/ir/dorehami/app/Config.kt` تعریف شده است. پیش از اتصال یا انتشار، وجود سرویس، TLS، قرارداد مسیرها و رفتار خطا باید از سمت بک‌اند تأیید شود. هیچ کلید یا رمز محرمانه‌ای نباید در سورس یا فایل‌های قابل انتشار قرار گیرد.

## اصول توسعه

- تغییرات ابتدا روی شاخه کاری مستقل انجام می‌شوند.
- شاخه `main` بدون تأیید صریح مالک تغییر نمی‌کند.
- تغییرات از طریق Pull Request، بازبینی diff و موفقیت CI پیشنهاد می‌شوند.
- هیچ قابلیت محصولی مصوبی با ساده‌سازی فنی حذف یا جایگزین نمی‌شود.
- کلید امضای release و اسرار محیط عملیاتی فقط در مخزن امن Secrets نگهداری می‌شوند.
